# Dataset

`customer_churn_raw.csv` is a reproducible **synthetic teaching dataset**, not real customer data. It contains 1,800 records and 11 model input features, a customer identifier, and a binary `churn` label (`Yes` / `No`). The fixed generator seed is `2026`; use `python scripts/generate_dataset.py` to recreate the CSV.

The sample intentionally includes blanks in numeric and categorical input columns so the preprocessing exercises can demonstrate missing-value audits and imputation. The target and customer identifier are kept complete. Churn labels are sampled from a seeded probability model based on contract, tenure, charges, service, support, and a few household attributes. The target is therefore useful for reproducible teaching and API smoke tests, but **the generated relationships are not evidence about a real telecom business**.

The project uses the raw CSV for model evaluation. `outputs/preprocessed_customer_churn.csv` and the selected-feature export are generated by Week 1 for demonstration; model pipelines independently fit preprocessing inside the training split or cross-validation folds to avoid leakage.
